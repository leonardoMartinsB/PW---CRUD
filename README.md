## ✨ Sobre o Projeto

Este projeto é um sistema de **CRUD** (Create, Read, Update, Delete) completo, desenvolvido como uma das primeiras experiências de integração entre o **front-end** e o **back-end** com um banco de dados.

Utilizando **PHP** para a lógica do servidor e **MySQL** para a persistência dos dados, a aplicação simula um sistema de gerenciamento onde é possível **Criar**, **Ler**, **Atualizar** e **Deletar** registros. Para a execução local, foi utilizado o **XAMPP** como um ambiente de desenvolvimento que simula um servidor web.

🔹 Principais destaques:

* ✅ Demonstração prática dos 4 pilares de um sistema de gerenciamento de dados (CRUD)
* ✅ Conexão e manipulação de um banco de dados **MySQL** com **PHP**
* ✅ Estrutura de arquivos e pastas organizada para um projeto **full-stack**
* ✅ Uso de **XAMPP** para simulação de servidor e ambiente de banco de dados

## 🛠️ Tecnologias Utilizadas

* **HTML5** e **CSS3** → Estrutura e estilização das páginas
* **PHP** → Lógica de back-end para processamento dos dados e conexão com o banco
* **MySQL** → Sistema de gerenciamento de banco de dados relacional
* **XAMPP** → Ambiente de desenvolvimento local (Apache, MySQL, PHP)
